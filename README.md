# 🏗️ OrçaObra

> **Seu orçamento profissional, sem complicação.**

O **OrçaObra** é um aplicativo web focado na criação rápida de orçamentos profissionais para a construção civil. O objetivo principal é permitir que qualquer profissional, mesmo sem muita intimidade com tecnologia, consiga criar e enviar um orçamento direto pelo celular ou computador em poucos minutos.

---

## Para quem é o projeto?
O sistema foi feito sob medida para profissionais autônomos e pequenos prestadores de serviços, como:
*   Pedreiros e Empreiteiros
*   Pintores e Azulejistas
*   Eletricistas e Encanadores
*   Gesseiros e Técnicos em geral

---

## O que o OrçaObra faz?
*   **Acesso Rápido:** Dashboard simples para ver o que está pendente, aprovado ou concluído.
*   **Passo a Passo Simples:** Criação de orçamentos guiada (Cliente ➔ Obra ➔ Serviços ➔ Materiais ➔ Valores).
*   **Salvamento Automático:** Não perde os dados se você fechar a página sem querer.
*   **Foco no Celular:** Funciona perfeitamente na tela do celular para quem está trabalhando direto na obra.
*   **Orçamentos Completos:** Separação clara entre o valor da mão de obra (serviços) e o valor dos materiais.
*   **Pronto para Enviar:** Permite gerar o orçamento em PDF para compartilhar direto com o cliente.

---

## Tecnologias Utilizadas
O projeto está sendo construído utilizando as seguintes tecnologias básicas da web:
*   **HTML5:** Para estruturar todo o conteúdo e os formulários do aplicativo.
*   **CSS3:** Para aplicar a identidade visual moderna em **Azul-marinho, Branco e Laranja**, além de garantir que o layout se adapte perfeitamente a celulares e computadores.
*   **JavaScript:** Para fazer os cálculos automáticos de valores, controlar o passo a passo do orçamento e salvar o progresso do usuário.

---

## 🎨 Identidade Visual e Regras do App
*   **Cores:** Identidade moderna mantendo o uso de **Azul-marinho, Branco e Laranja**.
*   **Simplicidade Total:** O sistema **não é um ERP** cheio de telas complicadas. Ele é focado apenas no orçamento.
*   **Linguagem Clara:** Textos simples, sem termos técnicos difíceis ou cadastros burocráticos obrigatórios.
